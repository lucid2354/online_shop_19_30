Техническое задание для дипломной работы: Интернет-магазин на Django
Общее описание
Разработать веб-приложение интернет-магазина на фреймворке Django.
Веб-приложение должно предоставлять пользователям возможность регистрации и входа в систему,
просмотра каталога товаров, разделенных по категориям, добавления товаров в корзину и в избранное,
поиска товаров по названию и оставления отзывов к товарам.

Основные требования:

1. Регистрация и вход в аккаунт
* Реализовать систему регистрации и входа в аккаунт с использованием аутентификации Django.
* Предусмотреть валидацию данных формы регистрации.

2. Вывод категорий и товаров
* Разработать модели категорий и товаров. Каждый товар должен быть связан с определенной категорией.
* Реализовать отображение списка категорий и товаров, принадлежащих каждой категории.

3. Логика корзины пользователя
* Реализовать функциональность добавления товаров в корзину, изменения количества товаров и удаления товаров из корзины.
* Корзина должна быть доступна только зарегистрированным пользователям.

4. Поиск товаров
* Реализовать возможность поиска товаров по названию среди всех категорий.
* Поиск должен быть реализован через текстовое поле ввода.

5. Отзывы к товарам
* Позволить зарегистрированным пользователям оставлять отзывы к товарам.
* Каждый товар может иметь несколько отзывов от разных пользователей.

6. Избранное
* Реализовать возможность добавления товаров в избранное для зарегистрированных пользователей.
* Предоставить интерфейс для просмотра и управления списком избранных товаров.

Технические требования:
* Веб-приложение должно быть разработано на фреймворке Django последней стабильной версии.
* Для фронтенда можно использовать готовые шаблоны на HTML и CSS или разработать собственный дизайн.
* Использовать базу данных SQLite для разработки и тестирования.
* Реализовать миграции для всех моделей данных.
* Применить систему управления статическими файлами и медиафайлами Django для обработки изображений товаров.
* Обеспечить безопасность пользовательских данных и аутентификационной информации.
* Предусмотреть обработку исключений и ошибок в пользовательском интерфейсе.
Дополнительные требования
* Реализовать административный интерфейс для управления категориями, товарами, отзывами и заказами.
* Подготовить документацию к проекту, включающую инструкцию по развертыванию и настройке веб-приложения.
Сдача работы
Дипломная работа сдается в виде исходного кода на электронном носителе или в виде ссылки на репозиторий на GitHub.
 Также необходимо предоставить отчет, содержащий обзор функциональности проекта, скриншоты интерфейса и инструкцию по запуску проекта.
