# Интернет-магазин

Учебный проект интернет-магазина, разработанный на Django.

## О проекте

Веб-приложение интернет-магазина с каталогом товаров, категориями, поиском, регистрацией и авторизацией пользователей.

## Функционал

- Просмотр каталога товаров
- Просмотр товаров по категориям
- Поиск товаров
- Страница отдельного товара
- Регистрация и авторизация пользователей
- Добавление товаров в корзину
- Избранные товары
- Добавление отзывов и оценок
- Административная панель Django

## Технологии

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite
